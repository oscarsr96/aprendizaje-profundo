TEMA 1 Introduccion y Motivacion
Limitaciones del Perceptron Simple

El perceptron simple, propuesto por Frank Rosenblatt en 1958, es capaz de aprender funciones linealmente separables: aquellas en las que existe un hiperplano que divide correctamente las clases en el espacio de entrada. Sin embargo, problemas aparentemente sencillos como la funcion logica XOR demuestran su incapacidad fundamental.

⚠
El problema XOR fue utilizado por Minsky y Papert en 1969 para demostrar que el perceptron simple no puede resolver problemas no linealmente separables. Esto genero el primer "invierno de la IA" hasta el redescubrimiento de la retropropagacion.
Solucion: Capas Ocultas

La solucion al problema de la linealidad consiste en apilar multiples capas de perceptrones. Las capas intermedias (ocultas) aprenden representaciones internas del problema — transformaciones no lineales del espacio de entrada que hacen que el problema resulte linealmente separable en las capas superiores.

Intuitivamente, cada capa oculta reescribe los datos en un nuevo espacio de caracteristicas. Para XOR, una capa oculta con dos neuronas puede crear una nueva base donde las cuatro combinaciones de entrada se distribuyen de forma separable.

Contexto Historico
1969 — Minsky y Papert

Demuestran las limitaciones del perceptron simple en su libro "Perceptrons". Señalan que un perceptron de una sola capa no puede resolver XOR, frenando la investigacion en redes neuronales durante mas de una decada.

1986 — Rumelhart, Hinton y Williams

Publican "Learning representations by back-propagating errors" en Nature. Presentan el algoritmo de retropropagacion del gradiente, que permite entrenar redes multicapa de manera eficiente, relanzando el campo del aprendizaje profundo.

Teorema de Aproximacion Universal

Hornik (1991) demuestra que un MLP con una sola capa oculta suficientemente grande y funciones de activacion no lineales puede aproximar cualquier funcion continua con precision arbitraria.

2006 en adelante — Deep Learning

Hinton y Salakhutdinov introducen el preentrenamiento no supervisado. LeCun, Bengio y Hinton (Premio Turing 2018) consolidan el aprendizaje profundo como paradigma dominante en inteligencia artificial.

TEMA 2 Arquitectura del Perceptron Multicapa
Componentes de la Arquitectura

Un Perceptron Multicapa (MLP) esta compuesto por tres tipos de capas organizadas de forma secuencial:

  • Capa de entrada: recibe el vector de caracteristicas x ∈ ℝn. No realiza computo; simplemente distribuye las señales.
  • Capas ocultas: una o mas capas intermedias que aprenden representaciones jerarquicas. Cada neurona aplica una transformacion afin seguida de una funcion de activacion no lineal.
  • Capa de salida: produce la prediccion final. Su estructura depende de la tarea (regresion, clasificacion binaria, clasificacion multiclase).
Notacion Matematica

Utilizamos la siguiente notacion estandar para describir un MLP de L capas:

Notacion por capas W(l) ∈ ℝnl × nl-1 — Matriz de pesos de la capa l
b(l) ∈ ℝnl — Vector de sesgos (bias) de la capa l
z(l) = W(l) a(l-1) + b(l) — Pre-activacion de la capa l
a(l) = f(l)(z(l)) — Activacion de la capa l (aplicando f elemento a elemento)
Capas Totalmente Conectadas (Dense)

En un MLP clasico, cada neurona de una capa se conecta con todas las neuronas de la capa anterior. Esta conectividad completa se denomina fully connected o dense. Si la capa l-1 tiene nl-1 neuronas y la capa l tiene nl, entonces la matriz W(l) contiene nl × nl-1 parametros entrenables, mas nl sesgos.

💡
Numero de parametros: Para un MLP con capas de tamaños [3, 4, 4, 2], el total de parametros es: (3×4 + 4) + (4×4 + 4) + (4×2 + 2) = 16 + 20 + 10 = 46 parametros. En redes profundas modernas, este numero puede superar los miles de millones.
TEMA 3 Propagacion hacia Adelante (Forward Propagation)
Formulacion Matematica

La propagacion hacia adelante consiste en calcular, capa por capa, las activaciones desde la entrada hasta la salida. Para cada capa l = 1, 2, ..., L:

Propagacion capa a capa z(l) = W(l) · a(l-1) + b(l)
a(l) = f(l)(z(l))
donde a(0) = x (vector de entrada) y ŷ = a(L) (prediccion)
Notacion Matricial para Batches

En la practica, procesamos multiples ejemplos simultaneamente. Si m es el tamaño del batch y organizamos los ejemplos en columnas, la propagacion se extiende de forma directa:

Formulacion en batch (m ejemplos) X ∈ ℝn0 × m,   Z(l) = W(l) A(l-1) + b(l) (broadcasting)
A(l) = f(l)(Z(l)) ∈ ℝnl × m
Ejemplo Numerico Detallado

Consideremos una red con 2 entradas, 1 capa oculta con 2 neuronas y 1 salida. Usamos la funcion sigmoide como activacion. Los parametros son:

Arquitectura: [2 → 2 → 1], activacion sigmoide W(1) = [[1, 2], [3, 1]],   b(1) = [0, 0]
W(2) = [[1, -1]],   b(2) = [0]
Entrada: x = [0.5, 0.8]ᵀ
Paso 1 — Pre-activacion capa oculta
z(1)1 = 1×0.5 + 2×0.8 + 0 = 0.5 + 1.6 = 2.1
z(1)2 = 3×0.5 + 1×0.8 + 0 = 1.5 + 0.8 = 2.3
Paso 2 — Activacion capa oculta (sigmoide)
a(1)1 = σ(2.1) = 1/(1 + e-2.1) ≈ 0.8909
a(1)2 = σ(2.3) = 1/(1 + e-2.3) ≈ 0.9089
Paso 3 — Pre-activacion capa de salida
z(2) = 1×0.8909 + (-1)×0.9089 + 0 = 0.8909 - 0.9089 = -0.018
Paso 4 — Activacion capa de salida (sigmoide)
ŷ = a(2) = σ(-0.018) = 1/(1 + e0.018) ≈ 0.4955

La red produce una prediccion de aproximadamente 0.4955, lo que significa que asigna probabilidad del 49.55% a la clase positiva. Esto evidencia la necesidad de entrenamiento: con pesos aleatorios, la red predice de forma arbitraria.

TEMA 4 Funciones de Activacion

Las funciones de activacion introducen la no linealidad esencial para que los MLPs aprendan funciones complejas. Sin ellas, una red multicapa colapsaria en una simple transformacion lineal.

Sigmoide (σ)
Formula σ(z) = 1 / (1 + e-z)
σ'(z) = σ(z) · (1 - σ(z))
Rango: (0, 1)

Propiedades: Salida interpretable como probabilidad. Suave y diferenciable en todo su dominio. Saturacion en valores extremos.

Problema del gradiente evanescente: cuando |z| es grande, σ'(z) ≈ 0, los gradientes se vuelven practicamente nulos en capas profundas.

Tangente Hiperbolica (tanh)
Formula tanh(z) = (ez - e-z) / (ez + e-z)
tanh'(z) = 1 - tanh²(z)
Rango: (-1, 1)

Ventaja sobre sigmoide: centrada en cero. Esto facilita el entrenamiento porque los gradientes pueden ser positivos o negativos, evitando actualizaciones sistematicamente sesgadas.

Sigue sufriendo del problema del gradiente evanescente en valores extremos, aunque con derivada maxima mayor (1 vs 0.25).

ReLU (Rectified Linear Unit)
Formula ReLU(z) = max(0, z)
ReLU'(z) = 1 si z > 0, 0 si z < 0
Rango: [0, +∞)

Ventajas: computacionalmente eficiente, no sufre gradiente evanescente para valores positivos, induce esparcidad en las activaciones (muchas neuronas en cero).

Dying ReLU: si una neurona recibe siempre entradas negativas, su gradiente es cero y nunca se actualiza. El uso de tasas de aprendizaje elevadas puede provocar este problema.

Leaky ReLU y Variantes

Para mitigar el problema del Dying ReLU, existen varias alternativas:

  • Leaky ReLU: f(z) = z si z > 0, αz si z ≤ 0, con α = 0.01 tipicamente.
  • ELU (Exponential Linear Unit): f(z) = z si z > 0, α(ez-1) si z ≤ 0. Salidas negativas con media cero.
  • SELU (Scaled ELU): normalizacion automatica en redes profundas.
  • GELU (Gaussian Error Linear Unit): usado en transformers modernos (BERT, GPT).
Softmax

La funcion Softmax se usa exclusivamente en la capa de salida para clasificacion multiclase. Convierte un vector de puntuaciones en una distribucion de probabilidad:

Softmax — clasificacion multiclase (K clases) Softmax(zk) = ezk / ∑j=1K ezj
Todas las salidas suman 1: ∑ Softmax(zk) = 1

TEMA 5 Funcion de Perdida (Loss Function)

La funcion de perdida (o funcion de coste) cuantifica como de lejos esta la prediccion de la red del valor real. El objetivo del entrenamiento es minimizar esta funcion respecto a los parametros de la red.

Error Cuadratico Medio (MSE) — Regresion
Mean Squared Error — para tareas de regresion LMSE = (1/m) ∑i=1m (yi - ŷi)2

El MSE penaliza en mayor medida los errores grandes (por el cuadrado). Es diferenciable en todo su dominio y convexo para modelos lineales, pero no necesariamente para redes neuronales.

  • Sensible a outliers: errores grandes tienen impacto cuadratico en la perdida.
  • Alternativa: MAE (Error Absoluto Medio), mas robusta a valores extremos.
  • Alternativa: Huber Loss, combinacion de MSE y MAE.
Entropia Cruzada Binaria — Clasificacion Binaria
Binary Cross-Entropy — para clasificacion con 2 clases LBCE = -(1/m) ∑i=1m [ yi log(ŷi) + (1-yi) log(1-ŷi) ]

Derivada directamente de la maxima verosimilitud bajo el modelo de Bernoulli. Cuando ŷ → 0 y el verdadero es y = 1, la perdida tiende a infinito — lo que fuerza a la red a corregir predicciones confiadas pero incorrectas.

Entropia Cruzada Categorica — Clasificacion Multiclase
Categorical Cross-Entropy — con Softmax en la salida (K clases) LCE = -(1/m) ∑i=1m ∑k=1K yik log(ŷik)

Con codificacion one-hot, la formula simplifica a L = -(1/m) ∑i log(ŷi,verdadero): solo el logaritmo de la probabilidad asignada a la clase correcta importa.

💡
Eleccion de la funcion de perdida: La combinacion Softmax + Entropia Cruzada es numericamente mas estable que calcularlos por separado. Los frameworks modernos (TensorFlow, PyTorch) implementan esta combinacion de forma conjunta en funciones como CrossEntropyLoss o sparse_categorical_crossentropy.
TEMA 6 Retropropagacion (Backpropagation)
La Regla de la Cadena

La retropropagacion es una aplicacion eficiente de la regla de la cadena del calculo diferencial a grafos computacionales. Para una funcion compuesta L = L(a(z(w))):

Regla de la cadena ∂L / ∂w = (∂L / ∂a) · (∂a / ∂z) · (∂z / ∂w)
Derivacion Paso a Paso — Red de 2 Capas

Para nuestra red ejemplo [2 → 2 → 1] con sigmoide y perdida MSE, calculamos los gradientes desde la salida hacia la entrada:

Paso 1 — Gradiente de la perdida respecto a la salida
L = (y - ŷ)2
∂L/∂ŷ = -2(y - ŷ) = -2(y - a(2))
Paso 2 — Gradiente a traves de la activacion de salida
∂L/∂z(2) = (∂L/∂a(2)) · σ'(z(2))
σ'(z(2)) = a(2)(1 - a(2)) = 0.4955 × 0.5045 ≈ 0.2498
Paso 3 — Gradiente respecto a W(2) y b(2)
∂L/∂W(2) = (∂L/∂z(2)) · (a(1))ᵀ
∂L/∂b(2) = ∂L/∂z(2)
Paso 4 — Propagacion del gradiente a la capa oculta
∂L/∂a(1) = (W(2))ᵀ · (∂L/∂z(2))
∂L/∂z(1) = ∂L/∂a(1) ⊙ f'(z(1)) (producto elemento a elemento)
Paso 5 — Gradiente respecto a W(1) y b(1)
∂L/∂W(1) = (∂L/∂z(1)) · xᵀ
∂L/∂b(1) = ∂L/∂z(1)
📖
Regla general para cualquier capa l: El gradiente que llega a la capa l es δ(l) = (W(l+1))ᵀ δ(l+1) ⊙ f'(z(l)). Este delta representa el "error" que cada neurona ha contribuido a la perdida total.
TEMA 7 Descenso del Gradiente (Gradient Descent)
Regla de Actualizacion

Una vez calculados los gradientes mediante retropropagacion, actualizamos todos los parametros de la red en la direccion opuesta al gradiente, ya que el gradiente apunta hacia el maximo crecimiento de la perdida:

Regla de actualizacion del descenso del gradiente W(l) ← W(l) − η · ∂L/∂W(l)
b(l) ← b(l) − η · ∂L/∂b(l)
donde η (eta) es la tasa de aprendizaje (learning rate)

Optimizadores Avanzados
Adam (Adaptive Moment Estimation)

Combina Momentum y RMSProp. Mantiene una media movil exponencial de los gradientes (primer momento) y sus cuadrados (segundo momento). Tasa de aprendizaje adaptativa por parametro. Es el optimizador por defecto en la mayoria de aplicaciones.

mt = β1mt-1 + (1-β1)gt
vt = β2vt-1 + (1-β2)gt²
W ← W − η · m̂t / (√v̂t + ε)
RMSProp

Adapta la tasa de aprendizaje de cada parametro dividiendo por la raiz cuadrada de una media movil de los cuadrados de los gradientes recientes. Especialmente util para redes recurrentes (RNN).

vt = βvt-1 + (1-β)gt²
W ← W − (η / √(vt + ε)) · gt
🔎
Valores tipicos de hiperparametros: Learning rate η ∈ [0.0001, 0.01]; para Adam: β1=0.9, β2=0.999, ε=10-8. El mini-batch mas comun es de 32 o 64 ejemplos.
TEMA 8 Regularizacion y Generalizacion
Sobreajuste vs Subajuste

El objetivo del aprendizaje automatico no es memorizar los datos de entrenamiento, sino generalizar a ejemplos nuevos no vistos. Los dos extremos del espectro son:

Dropout

El Dropout (Srivastava et al., 2014) es una tecnica de regularizacion que, durante el entrenamiento, desactiva aleatoriamente una fraccion p de neuronas en cada iteracion. Esto impide que la red dependa de neuronas especificas, forzando representaciones mas distribuidas y robustas.

⚠
Importante: Durante la inferencia (prediccion), el Dropout se desactiva y todas las neuronas estan activas. Los pesos se escalan por (1-p) para compensar, o equivalentemente se multiplican las activaciones por 1/(1-p) durante el entrenamiento (inverted dropout).
Regularizacion L1 y L2
Terminos de regularizacion añadidos a la funcion de perdida L1 (Lasso):   Lreg = L + λ ∑i |wi|
L2 (Ridge / Weight Decay):   Lreg = L + λ ∑i wi²
  • L2 (mas comun): penaliza los pesos grandes uniformemente. El gradiente añadido es 2λw, lo que "decae" los pesos hacia cero en cada actualizacion.
  • L1: induce esparcidad — muchos pesos se vuelven exactamente cero. Equivalente a la seleccion automatica de caracteristicas.
Early Stopping

El early stopping (parada temprana) monitorea la perdida en el conjunto de validacion durante el entrenamiento. Cuando esta deja de mejorar durante un numero de epocas consecutivas (llamado patience), se detiene el entrenamiento y se recuperan los pesos del mejor modelo encontrado.

TEMA 9 Ejemplo Completo: Clasificacion XOR
Definicion del Problema

La funcion XOR es el ejemplo canónico de problema no lineal. Con una red [2 → 2 → 1] podemos resolverlo exactamente. Utilizaremos los siguientes pesos ya entrenados para ilustrar como el MLP crea una nueva representacion del espacio de entrada:

Dataset XOR completo x = [0,0] → y = 0  |  x = [0,1] → y = 1
x = [1,0] → y = 1  |  x = [1,1] → y = 0
Propagacion hacia Adelante con Pesos Entrenados

Usamos pesos representativos para el XOR. La neurona h₁ detecta OR (al menos uno activo) y la neurona h₂ detecta NAND (no ambos activos). La combinacion en la salida implementa XOR:

Entrada (x₁, x₂)h₁ (OR)h₂ (NAND)Salida ŷXOR realCorrecto?
(0, 0)~0.00~1.00~0.000✓
(0, 1)~1.00~1.00~1.001✓
(1, 0)~1.00~1.00~1.001✓
(1, 1)~1.00~0.00~0.000✓
Nueva Representacion y Frontera de Decision

La clave esta en que la capa oculta transforma el espacio de entrada no separable en un nuevo espacio donde los datos si son linealmente separables:

💡
La clave conceptual del MLP: las capas ocultas transforman el espacio de representacion hasta que el problema se vuelve linealmente separable. Cada capa aprende a "doblar" o "estirar" el espacio de entrada de forma util para la tarea.
TEMA 10 Implementacion en Python (desde cero con NumPy)
Clase MLP Completa

A continuacion se presenta una implementacion completa de un MLP desde cero usando unicamente NumPy, entrenado para resolver XOR. Incluye propagacion hacia adelante, retropropagacion y descenso del gradiente.

# ================================================================ # MLP desde cero con NumPy — Resolucion del problema XOR # Aprendizaje Profundo — CUNEF Universidad # ================================================================ import numpy as np # ── Funciones de activacion ────────────────────────────────────── def sigmoid(z): """Funcion sigmoide y su derivada.""" return 1.0 / (1.0 + np.exp(-z)) def sigmoid_deriv(z): s = sigmoid(z) return s * (1 - s) def relu(z): return np.maximum(0, z) def relu_deriv(z): return (z > 0).astype(float) # ── Clase Principal del MLP ────────────────────────────────────── class MLP: def __init__(self, capas, tasa_aprendizaje=0.1, activacion='sigmoid'): """ Inicializa el MLP. capas: lista con numero de neuronas por capa, ej. [2, 4, 1] tasa_aprendizaje: eta (learning rate) activacion: 'sigmoid' o 'relu' """ self.capas = capas self.lr = tasa_aprendizaje self.L = len(capas) - 1 # numero de capas con pesos # Seleccionar funcion de activacion if activacion == 'sigmoid': self.f = sigmoid self.df = sigmoid_deriv else: self.f = relu self.df = relu_deriv # Inicializacion aleatoria de pesos (Xavier / He simplificado) self.W = {} self.b = {} for l in range(1, self.L + 1): escala = np.sqrt(2.0 / capas[l - 1]) self.W[l] = np.random.randn(capas[l], capas[l-1]) * escala self.b[l] = np.zeros((capas[l], 1)) def forward(self, X): """ Propagacion hacia adelante. X: matriz de entrada (n_entradas x m_ejemplos) Devuelve: prediccion final y caches intermedios. """ self.cache_z = {} # pre-activaciones self.cache_a = {} # activaciones self.cache_a[0] = X for l in range(1, self.L + 1): z = self.W[l] @ self.cache_a[l-1] + self.b[l] self.cache_z[l] = z # Ultima capa: sigmoide para clasificacion binaria if l == self.L: self.cache_a[l] = sigmoid(z) else: self.cache_a[l] = self.f(z) return self.cache_a[self.L] def backward(self, Y): """ Retropropagacion del gradiente. Y: etiquetas reales (1 x m_ejemplos) Devuelve: gradientes de W y b para cada capa. """ m = Y.shape[1] grads_W = {} grads_b = {} # Gradiente de la perdida BCE respecto a la salida dA = -(Y / self.cache_a[self.L] - (1 - Y) / (1 - self.cache_a[self.L] + 1e-8)) for l in reversed(range(1, self.L + 1)): # Multiplicar por derivada de activacion dZ = dA * sigmoid_deriv(self.cache_z[l]) \ if l == self.L \ else dA * self.df(self.cache_z[l]) # Gradientes de pesos y sesgos grads_W[l] = (dZ @ self.cache_a[l-1].T) / m grads_b[l] = np.mean(dZ, axis=1, keepdims=True) # Propagar hacia la capa anterior dA = self.W[l].T @ dZ return grads_W, grads_b def actualizar(self, grads_W, grads_b): """Descenso del gradiente: w = w - lr * grad_w""" for l in range(1, self.L + 1): self.W[l] -= self.lr * grads_W[l] self.b[l] -= self.lr * grads_b[l] def perdida_bce(self, Y, Y_pred): """Entropia cruzada binaria.""" m = Y.shape[1] eps = 1e-8 return -np.mean( Y * np.log(Y_pred + eps) + (1 - Y) * np.log(1 - Y_pred + eps) ) def entrenar(self, X, Y, epocas=10000, verbose=True): """Bucle de entrenamiento completo.""" historial_perdida = [] for epoca in range(epocas): # Paso adelante Y_pred = self.forward(X) # Calcular perdida L = self.perdida_bce(Y, Y_pred) historial_perdida.append(L) # Retropropagacion grads_W, grads_b = self.backward(Y) # Actualizar parametros self.actualizar(grads_W, grads_b) # Mostrar progreso cada 1000 epocas if verbose and (epoca % 1000 == 0): print(f"Epoca {epoca:5d} | Perdida: {L:.6f}") return historial_perdida def predecir(self, X, umbral=0.5): """Prediccion binaria con umbral.""" probs = self.forward(X) return (probs >= umbral).astype(int) # ── Entrenamiento en XOR ───────────────────────────────────────── if __name__ == "__main__": np.random.seed(42) # reproducibilidad # Dataset XOR: columnas = ejemplos X = np.array([[0, 0, 1, 1], [0, 1, 0, 1]], dtype=float) Y = np.array([[0, 1, 1, 0]], dtype=float) # Crear y entrenar el MLP: 2 entradas, 4 ocultas, 1 salida red = MLP(capas=[2, 4, 1], tasa_aprendizaje=0.5, activacion='sigmoid') historial = red.entrenar(X, Y, epocas=10000, verbose=True) # Evaluacion final predicciones = red.predecir(X) print("\n=== Resultados Finales ===") print(f"Predicciones: {predicciones.flatten()}") print(f"Etiquetas: {Y.flatten().astype(int)}") precision = np.mean(predicciones == Y) * 100 print(f"Precision: {precision:.1f}%")

Salida esperada al ejecutar: Tras ~5000-10000 epocas con lr=0.5, la red converge a precision del 100% en XOR. La perdida desciende de ~0.69 (prediccion aleatoria) a valores proximos a 0. Para replicar: python mlp_xor.py

Tarjeta de Referencia de Formulas
Propagacion hacia adelante z(l) = W(l)a(l-1) + b(l)
a(l) = f(l)(z(l))
ŷ = a(L)
Retropropagacion δ(L) = ∂L/∂z(L)
δ(l) = (W(l+1))ᵀδ(l+1) ⊙ f'(z(l))
∂L/∂W(l) = δ(l)(a(l-1))ᵀ
Funciones de activacion σ(z) = 1/(1+e-z)
tanh(z) = (ez-e-z)/(ez+e-z)
ReLU(z) = max(0, z)
Funciones de perdida MSE = (1/m)∑(y-ŷ)²
BCE = -(1/m)∑[y log ŷ + (1-y)log(1-ŷ)]
CE = -(1/m)∑k yk log(ŷk)
