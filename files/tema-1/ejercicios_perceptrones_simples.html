EJERCICIO 3 Limitación del perceptrón: el problema XOR
Enunciado

Uno de los resultados más importantes en la historia de la inteligencia artificial es que un perceptrón simple NO puede resolver el problema XOR. Demuestra esta afirmación mediante dos vías complementarias:

  1. Argumento algebraico: Muestra que no existe ningún conjunto de pesos (w₁, w₂, b) que clasifique correctamente todos los puntos de la tabla XOR.
  2. Argumento geométrico: Explica por qué el problema XOR no es linealmente separable.
Tabla XOR
x₁x₂XORClase
000Negativa
011Positiva
101Positiva
110Negativa
Observación clave: Los puntos de clase 1 son (0,1) y (1,0); los de clase 0 son (0,0) y (1,1). Forman un patrón en diagonal opuesta.
Plano geométrico XOR
Clase 0 (○) = {(0,0),(1,1)}    Clase 1 (●) = {(0,1),(1,0)}
Argumento Algebraico (Guía)

Para que el perceptrón clasifique correctamente, deben cumplirse simultáneamente las cuatro condiciones:

(1) b ≥ 0                  [XOR(0,0)=0 ⇒ z<0]
(2) w₂ + b ≥ 0          [XOR(0,1)=1 ⇒ z≥0]
(3) w₁ + b ≥ 0          [XOR(1,0)=1 ⇒ z≥0]
(4) w₁ + w₂ + b < 0    [XOR(1,1)=0 ⇒ z<0]

Sumando (2) y (3): w₁ + w₂ + 2b ≥ 0. De (1): b ≥ 0, luego w₁ + w₂ + b ≥ 0. Esto contradice (4). Por tanto, no existe solución. ■

💡
Conclusión: El XOR no es linealmente separable: los dos grupos de puntos no pueden separarse con una única recta en el plano. Se necesita al menos una capa oculta (red MLP). Minsky y Papert demostraron esto en 1969 en su libro Perceptrons.

EJERCICIO 6 Implementación en Python: perceptrón para la puerta OR
Enunciado

Implementa un perceptrón simple en Python capaz de aprender la función lógica OR de dos entradas. El código debe incluir:

  1. La clase Perceptron con métodos predict y fit.
  2. La función de activación escalón.
  3. El bucle de entrenamiento con la regla del perceptrón.
  4. Impresión de los pesos finales y verificación sobre todos los ejemplos.
Código Python
# ─── Perceptrón Simple — Puerta lógica OR ─────────────────────────────────── import numpy as np class Perceptron: def __init__(self, tasa_aprendizaje=1.0, epocas=10): self.eta = tasa_aprendizaje # η: tasa de aprendizaje self.n_iter = epocas self.pesos = None # w₁, w₂, ..., wₙ self.sesgo = None # b def _escalon(self, z): """Función de activación escalón unitario.""" return np.where(z >= 0, 1, 0) def predict(self, X): """Calcula z = X·w + b y aplica la función escalón.""" z = np.dot(X, self.pesos) + self.sesgo return self._escalon(z) def fit(self, X, y): """Entrena el perceptrón con la regla de actualización de Rosenblatt.""" n_muestras, n_entradas = X.shape self.pesos = np.zeros(n_entradas) # Inicializar pesos a 0 self.sesgo = 0 for epoca in range(self.n_iter): errores_totales = 0 for xi, yi in zip(X, y): prediccion = self.predict(xi) error = yi - prediccion # δ = y - ŷ # Regla de actualización: Δwᵢ = η · δ · xᵢ self.pesos += self.eta * error * xi self.sesgo += self.eta * error errores_totales += int(error != 0) print(f"Época {epoca+1:2d} | Errores: {errores_totales} | " f"w={self.pesos} | b={self.sesgo}") if errores_totales == 0: print(" ✓ Convergencia alcanzada. Entrenamiento finalizado.") break return self # ─── Datos de entrenamiento: OR ───────────────────────────────────────────── X_or = np.array([[0, 0], [0, 1], [1, 0], [1, 1]]) y_or = np.array([0, 1, 1, 1]) # Etiquetas: puerta OR # ─── Entrenamiento ─────────────────────────────────────────────────────────── perceptron = Perceptron(tasa_aprendizaje=1.0, epocas=20) perceptron.fit(X_or, y_or) # ─── Verificación ──────────────────────────────────────────────────────────── print("\n--- Verificación final ---") for xi, yi in zip(X_or, y_or): pred = perceptron.predict(xi) ok = "OK" if pred == yi else "FALLO" print(f" OR{tuple(xi)} = {yi} → predicción = {pred} [{ok}]")

EJERCICIO 7 Teorema de convergencia del perceptrón
Enunciado

El Teorema de Convergencia del Perceptrón (Rosenblatt, 1962; Novikoff, 1962) establece condiciones formales bajo las cuales el algoritmo de aprendizaje del perceptrón garantiza encontrar una solución en un número finito de pasos. Responde razonadamente a las siguientes preguntas:

Parte A — Enunciado del Teorema

Enuncia el teorema de convergencia del perceptrón en tus propias palabras. ¿Qué condición debe satisfacer el conjunto de datos para que el teorema sea aplicable?

Hipótesis del Teorema (Novikoff, 1962) Sea D = {(xᵢ, yᵢ)} un conjunto de entrenamiento linealmente separable.
Existen w* y R > 0 tal que:   yᵢ · (w*ᵀ · xᵢ) ≥ γ > 0  ∀i    y    ||xᵢ|| ≤ R  ∀i

Entonces el número de actualizaciones de pesos k satisface:

k ≤ ( R · ||w*||γ )²
Parte B — Interpretación
  1. ¿Qué representa el cociente R / γ en el teorema? ¿Cómo afecta al número máximo de errores cometidos durante el entrenamiento?
  2. Si el conjunto de datos no es linealmente separable, ¿qué le ocurre al algoritmo del perceptrón? ¿Converge? Justifica tu respuesta.
  3. El margen de separabilidad γ mide la "holgura" entre la frontera de decisión y los puntos más cercanos. ¿Qué método de aprendizaje automático maximiza este margen?
Parte C — Demostración Esquemática

Completa los pasos clave de la demostración por inducción:

  1. Cota inferior: Demuestra que wᵀ(k) · w* ≥ k · γ tras k actualizaciones.
  2. Cota superior: Demuestra que ||w(k)||² ≤ k · R².
  3. Combinación: Usa la desigualdad de Cauchy-Schwarz para obtener el límite en k.
Desigualdad de Cauchy-Schwarz aplicada k² γ² ≤ (wᵀ(k) · w*)² ≤ ||w(k)||² · ||w*||² ≤ k · R² · ||w*||²   ⇒   k ≤ R² · ||w*||²γ²
